## Color Coding

### Status Badges
- **Trial Active**: Yellow background, yellow text
  `bg-yellow-100 text-yellow-800`
  
- **Paid Active**: Green background, green text
  `bg-green-100 text-green-800`
  
- **Expired**: Red background, red text
  `bg-red-100 text-red-800`
  
- **Pending**: Gray background, gray text
  `bg-gray-100 text-gray-800`

### Buttons
- **Primary (Subscribe)**: Blue to Indigo gradient
  `from-blue-600 to-indigo-600`
  
- **Secondary (View Details)**: Blue solid
  `bg-blue-600`
  
- **Manage**: Blue solid with hover
  `bg-blue-600 hover:bg-blue-700`

### Cards
- **Software Card**: White with shadow
  `bg-white shadow-md hover:shadow-xl`
  
- **Subscription Card**: White with border
  `bg-white border border-gray-200`

## Responsive Breakpoints

### Mobile (< 640px)
- Single column layout
- Stacked cards
- Full-width buttons
- Condensed spacing

### Tablet (640px - 1024px)
- Two column grid
- Medium card sizes
- Responsive navigation
- Optimized spacing

### Desktop (> 1024px)
- Three column grid
- Large card sizes
- Full navigation
- Generous spacing

## Accessibility Features

- **ARIA Labels**: All interactive elements
- **Keyboard Navigation**: Tab-friendly
- **Focus Indicators**: Visible focus states
- **Screen Reader Support**: Semantic HTML
- **Color Contrast**: WCAG AA compliant
- **Alt Text**: All images
